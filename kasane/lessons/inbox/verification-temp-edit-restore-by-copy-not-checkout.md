## ルール文

検証・撮影のための一時改変を元に戻すとき、未コミットの実装が載っている作業ツリーで `git checkout -- <ファイル>` / `git restore` を使わない。一時改変の前に対象ファイルを scratchpad へコピー退避し、復元はそのコピーからの上書きで行う (戻した後に md5 で一致確認)。`git checkout` はファイル単位で「一時改変だけ」を選べず、そのファイルの未コミット変更を全部消す。

## 経緯

- 2026-08-26 add-loading: 撮影用の一時改変 (ダイアログ先出し・刻み間隔延長) と本実装 (デモ項目追加) が同じファイルに同居していた。復元手段に `git checkout` を選んだ時点で本実装の喪失が確定した。コピー退避なら選択の余地なく安全だった

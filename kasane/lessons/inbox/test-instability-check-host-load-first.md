## ルール文

全件テスト実行の間欠失敗 (待ちのタイムアウト系) を実装・テストの欠陥と断定する前に、検証機の負荷状態を実測する — load average と居座りプロセス (孤児化した CPU 食い) を確認し、汚染があれば掃除してから反復実測する。切り分けには「HEAD (変更なし) での同一手順の反復」と「失敗テストが回ごとに入れ替わるか (変更と無関係な領域にも散るか)」を使う。負荷汚染下の実測値 (失敗率・所要時間) を判定の根拠にしない。

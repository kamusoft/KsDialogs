# monorepo 内消費者の座標追随の確認 (2026-09-08)

Android 座標のリネーム (jp.kamusoft:ksdialogs-core = View 系本体 / jp.kamusoft:ksdialogs = Compose 系) に
消費者 4 面 (samples/android・samples/kmp・kmp/ksdialogs-kmp・maui/android) を追随させた結果の抜粋。

## 1. samples/android — 直接依存 1 行と置換の解決先

コマンド: cd samples/android && ./gradlew :app:assembleDebug
> Task :app:assembleDebug
BUILD SUCCESSFUL in 26s
72 actionable tasks: 51 executed, 3 from cache, 18 up-to-date

コマンド: cd samples/android && ./gradlew -q :app:dependencyInsight --configuration debugCompileClasspath --dependency jp.kamusoft
(属性表は省略)

project ':android:ksdialogs-core'

     \--- debugCompileClasspath (requested jp.kamusoft:ksdialogs:0.1.0-SNAPSHOT)

app の直接依存は jp.kamusoft:ksdialogs の 1 行だけで、View 系本体は
project ':android:ksdialogs-core' として推移的に解決されている。

公開済み成果物へ解決される経路を塞ぐ安全装置として置いてある)。

## 3. 置換の実効 (本体ソースの変更が Sample に反映されるか)

android/ksdialogs-core の DialogTransitionRunner.kt のログ文言に一時的な目印
"KSDIALOGS_SUBSTITUTION_PROBE" を入れ、両 Sample を再ビルドして APK の dex を走査した。
目印は元ファイルのコピーからの復元で取り除き、git diff が空であることを確認済み。

samples/android (app/build/outputs/apk/debug/app-debug.apk):
  classes.dex: 0
  classes2.dex: 1
  classes3.dex: 0
  classes4.dex: 0
  classes5.dex: 0
  classes6.dex: 0
  classes7.dex: 0

samples/kmp (androidApp/build/outputs/apk/debug/androidApp-debug.apk):
  classes.dex: 0
  classes2.dex: 0
  classes3.dex: 1
  classes4.dex: 0
  classes5.dex: 0
  classes6.dex: 0
  classes7.dex: 0
  classes8.dex: 0

どちらの APK にも目印が 1 件入っており、公開済み成果物ではなくローカルの本体ソースが
使われている。

## 6. maui binding — aar パスと gradlew task 名の追随

改名後の aar を必ず作り直す経路を通すため、android/ksdialogs-core/build/outputs/aar/ の
ksdialogs-core-release.aar を削除してからビルドした。

コマンド: dotnet build maui/android/KsDialogs.Binding.Android/KsDialogs.Binding.Android.csproj
    30 個の警告 (BG8605 / BG8606 / BG8401。同梱するだけの aar に由来する既知の警告)
    0 エラー

生成された aar (ビルド後):
  android/ksdialogs-core/build/outputs/aar/ksdialogs-core-release.aar   309884 bytes
  maui/android/native/ksdialogs-maui-bridge/build/outputs/aar/ksdialogs-maui-bridge-release.aar   71114 bytes

同梱された aar の中身 (obj/Debug/net10.0-android/lp/ に展開されたもの):
  lp/4/jl/AndroidManifest.xml -> package="jp.kamusoft.ksdialogs"

同梱先が View 系本体 (namespace jp.kamusoft.ksdialogs) であり、Compose 系
(namespace jp.kamusoft.ksdialogs.compose) に入れ替わっていない。

## 実装で必要になった追加事項 (group 3 への申し送り)

- 作業コピーではバージョンカタログの相対パス `../../android/gradle/libs.versions.toml` が
  解決できないため、`settings.gradle.kts` に Gradle プロパティ `ksdialogs.catalog` の
  上書き口を設けた。コピーの中で走らせる呼び出しはすべてこれを渡す必要がある
- Xcode の "Build shared framework" フェーズは `KSDIALOGS_MODE` / `KSDIALOGS_REFERENCE` /
  `KSDIALOGS_VERSION` / `KSDIALOGS_CATALOG` を環境変数から受け取る。`xcodebuild` を呼ぶ側が
  export する
- `generic/platform=iOS Simulator` は arm64 と x86_64 の両方を作るが、共有モジュールの
  framework は arm64 simulator だけをリンクするため、Xcode project で
  `EXCLUDED_ARCHS[sdk=iphonesimulator*] = x86_64` を指定した

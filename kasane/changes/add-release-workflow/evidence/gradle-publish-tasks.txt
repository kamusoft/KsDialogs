# 4. automaticRelease = false の効き (自動公開に倒れないこと)

判別の道具: 発行設定の automaticRelease が真になると、plugin は publish タスクに
`enableAutomaticMavenCentralPublishing` タスクを依存として足す。task graph にこの名前が
出るかどうかが「自動公開に倒れているか」の印になる。

## 4-1. 印に判別力があることの確認 (作業木の外の probe プロジェクト)

同じ plugin 版 (com.vanniktech.maven.publish 0.37.0) を当てただけの最小プロジェクトを
作業木の外 (一時ディレクトリ) に作り、`mavenPublishing` の書き方だけを変えて比べた。
どちらの実行にも `-PmavenCentralAutomaticPublishing=true` を渡している。

  (a) publishToMavenCentral()                        引数を書かない
      $ ./gradlew publishToMavenCentral -PmavenCentralAutomaticPublishing=true --dry-run
      :emptyJavadocJar SKIPPED
      :enableAutomaticMavenCentralPublishing SKIPPED      <- 自動公開に倒れている
      :compileJava SKIPPED
      ... (中略)
      :publishToMavenCentral SKIPPED
      BUILD SUCCESSFUL

  (b) publishToMavenCentral(automaticRelease = false)  本リポジトリと同じ書き方
      $ ./gradlew publishToMavenCentral -PmavenCentralAutomaticPublishing=true \
          -PksExplicitFalse=1 --dry-run
      :emptyJavadocJar SKIPPED
      :compileJava SKIPPED
      ... (中略)
      :publishToMavenCentral SKIPPED
      BUILD SUCCESSFUL
      (`enableAutomaticMavenCentralPublishing` は出ない)

同じ入力 (property = true) で観測が (a) と (b) に分かれるので、この grep には
「指定が効いているか」を判別する力がある。probe プロジェクトは作業木には残していない。

plugin 本体の実装とも一致する: 引数を書かない呼び出しの既定値は Gradle プロパティ
`mavenCentralAutomaticPublishing` / `SONATYPE_AUTOMATIC_RELEASE` (既定 false) から読まれ、
真のとき publish タスクに `enableAutomaticMavenCentralPublishing` が依存として足される。

## 4-2. 本リポジトリの android/ と kmp/ の観測

  $ ./gradlew publishToMavenCentral -Pversion=0.0.0-alpha.1 \
      -PmavenCentralAutomaticPublishing=true --dry-run
  ...
  BUILD SUCCESSFUL

  $ (上の出力を grep) enableAutomaticMavenCentralPublishing
  android/ の一致件数: 0
  kmp/ の一致件数:     0

どちらも task graph に `prepareMavenCentralPublishing` は入っており (publish の graph を
見ていることの確認)、`enableAutomaticMavenCentralPublishing` だけが入らない。
upload は保留 (USER_MANAGED) で止まり、公開の可否は release workflow が枠ごとに決める。

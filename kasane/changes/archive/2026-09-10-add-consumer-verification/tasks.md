## 備考

- workflow の実装は github-workflow-skill、MAUI は csharp-impl-skill / maui-skill、Kotlin / Gradle は kotlin-impl-skill、Swift は swift-ui-impl-skill を参照する
- 翻案元のスクリプトの `rm -rf` は規約違反ではない (handbook cross/ci-script-deletion.md)。削除前の対象検証は写す
- README の修正は本変更で行わない (docs-refresh 経由)。壊れていれば 2.6 で止めて報告する
- release workflow からの呼び出し・smoke の正ケースの実証・`main` の必須 check 登録は phase-9 (proposal Non-Goals)

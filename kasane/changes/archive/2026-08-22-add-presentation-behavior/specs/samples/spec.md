# samples デルタ (add-presentation-behavior)

## ADDED Requirements

### Requirement: トランジションデモ

Sample はトランジションのデモをパリティ規約準拠で4形態 (iOS / Android / MAUI / KMP) に持つ (SHALL)。デモではプリセット (Fade / Slide 4方向 / Zoom / None) の選択、時間・イージングの調整、カスタムフック (自作の presentation / dismissal) の実演ができる。文言は ui/brief.md の文言表に、調整面の初期値・範囲・有効/無効・写像は同 brief の「調整面の規範表」に一字一句一致させ、操作部の読み上げは既存のパネル読み上げ規約に従う。

#### Scenario: [PB-SM-01] プリセットを選んで表示できる
- **GIVEN** トランジションデモを開いている
- **WHEN** プリセットと時間・イージングを選択してダイアログを表示する
- **THEN** 選択したプリセットの演出 (時間・イージングは規範表の写像どおり) でダイアログが表示・閉鎖され、結果が結果エリアに表示される。None 選択時は時間・イージングの調整が無効表示になる

#### Scenario: [PB-SM-02] カスタムフックの実演
- **GIVEN** トランジションデモを開いている
- **WHEN** Custom Hook を選択してダイアログを表示・閉鎖する
- **THEN** 自作フックによる演出で表示・閉鎖され、結果が表示に反映される

#### Scenario: [PB-SM-03] 4形態で同一デモが動く
- **GIVEN** 4形態の Sample アプリ
- **WHEN** それぞれでトランジションデモを実行する
- **THEN** 同じデモ項目・同じ操作で同等の観察結果になる (演出の見え方の細部は実機確認で記録)

# iOS 入場の初回フレーム — ちらつきの再現と解消の証跡

オーナーが実機で報告した「スライド系プリセットの入場時、最終位置のカードが 1 フレーム見えてから
画面外へ飛んで滑り込んでくる」症状の、修正前の再現と修正後の解消の記録 (2026-08-22)。

実行時挙動の検証規約に従い、**修正前に実環境で症状を再現し**、**修正後に同一手順で解消を確認**した A/B。

## 端末と対象

| 項目 | 値 |
|---|---|
| 端末 | iPhone 17 シミュレータ / iOS 26.5 (`<uuid>`) |
| アプリ | `samples/ios` の Sample (`jp.kamusoft.ksdialogs.samples.ios`)。本体は Local Swift Package 参照のため、修正の前後でそれぞれ再ビルド・再インストールした |
| 操作 | Transition Dialog → プリセット選択 → 時間 600 ms → `表示` |

## 観察の方法

1 フレーム (約 16.7 ms) の描画はスクリーンショットの連写では捕まえられないため、画面を録画してから
フレーム単位に切り出した。

```
xcrun simctl io <UDID> recordVideo --codec h264 <出力>.mp4
```

切り出しは AVFoundation (`AVAssetReader`) で全フレームを復号し、presentation timestamp 付きで
PNG に書き出す使い捨てのスクリプトで行った (ffmpeg は環境に無いため導入していない)。
シミュレータの録画は画面が変化したフレームだけを符号化するため、
`表示` をタップした瞬間から出現の演出が終わるまでが約 60 fps で連続して残る。

ファイル名の `fNNNN_SSS.SSS` は「動画中の通し番号 _ 秒」。

| `slide-up-f0003-6.480-offscreen.png` | 次のフレームでカードは消える (画面外へ飛び、ここから滑り込みが始まる) |

6.462 の 1 フレームだけカードが最終位置に出て、次のフレームで消える。オーナー報告と一致する。

### Zoom / Custom Hook

| フレーム | 観察 |
|---|---|
| `zoom-f0008-5.920-final-scale.png` | 演出の開始前に、カードが**縮小前の等倍**で描かれている |
| `custom-f0001-6.258.png` | 自作フックの開始状態 (下へ 80pt ずらした位置) が映った最初のフレーム |

Zoom / Custom Hook はフックの最初の処理で透明度も 0 にするため、Slide 系ほど目立つ形では出ない。
録画の粒度では不透明な最終位置のフレームまでは捕まらなかったが、原因は Slide 系と同一 (下記)。

## 原因

器はコンテンツを載せる時点で非表示にし、属性の凍結後に表示へ戻して presentation フックを始める。
このうち**表示へ戻す操作だけが同期的**に行われ、フックの開始は次のメインアクターのターンに回っていた。
その隙間に描画が 1 回入ると、フックがまだ何も置いていない = 最終位置のコンテンツが描かれる。

## 修正

表示へ戻す操作を進行を進める仕事の中へ移し、フックを子タスクではなく直接 `await` で呼ぶことで、
**表示とフックの最初の同期処理を同じ同期区間に入れた** (滑り込みなら画面外への移動、
zoom なら 0.8 倍、自作フックなら利用者の最初の処理まで)。間に描画の機会が入らない。

`Task.immediate` (Kotlin の `UNDISPATCHED` 相当) は iOS 26.0 以降でしか使えず、
このパッケージの最低対象 OS (iOS 17) では採用できないため、この形にした。

## 回帰テスト

実環境の確認に加えて、意図を固定するテストを 1 本置いた
(`ios/Tests/KsDialogsTests/DialogTransitionTests.swift` の
「中身の表示と presentation フックの開始の間に描画の機会がない」)。

器を直接組み立て、器が進行を始めたのと同じ同期区間で「後続のターンで走る目印」を積み、
フックの最初の同期処理からその目印がまだ立っていないことを見る。
つまり、表示とフックの間にメインアクターのターンの切れ目が無いことを直接固定している。

このテストは修正前のコードに対して 2 つの期待で失敗することを確認済み
(表示が同期的に済んでいること / 目印が先に立っていること)。

# ios-native デルタ (deliver-swiftui-content-safe-area-ios)

iOS の器 (Dialog・Loading・Toast) に載せた SwiftUI の中身から見える安全領域の差分だけを扱う。Scenario ID は `PB-IS-<NN>` (iOS の器の中の中身の安全領域)。3 機能は同じホストを通るため、Dialog で全条件を、Loading・Toast で代表の条件を固定する。

用語:
- 重なり: 中身の矩形 (窓の座標) と、窓の安全領域の外側 (システムの領域) が重なる幅。辺ごとに測る
- 端の軸: レイアウトの解で、その軸の位置が前端 (左 / 上) か後端 (右 / 下) に固定される軸。配置 start / end と、比率サイズを伴わない fill がこれに当たる。中央の軸: 位置が中央に固定される軸 (配置 center と、比率サイズを伴う fill)
- 要求サイズ: 器へ伝える中身の大きさ。今と同じく、制約を付けずに求めた中身の理想の大きさ
- 中身が受け取る安全領域: SwiftUI の中身の一番外側の View から見える、SwiftUI 標準の安全領域

共通の試験条件 (Scenario に書いていなければこれを使う):
- 縦長の窓: 393 × 852、安全領域は上 59・下 34・左右 0。横長の窓: 852 × 393、安全領域は左右 59・下 21・上 0
- 中身: 大きさが可変で、理想の大きさ 200 × 100 を求める SwiftUI の View (固定サイズの指定は使わない)
- 余白・移動量 (offset)・比率サイズは指定しない。基準領域と配置は各 Scenario のとおり

## ADDED Requirements

### Requirement: 窓全体基準で端の軸に付けた SwiftUI の中身は、器と安全領域の重なりを標準の安全領域として受け取る

基準領域が窓全体のとき、iOS の器に載せた SwiftUI の中身は、端の軸の各辺について、重なりと等しい値を SwiftUI 標準の安全領域として受け取る SHALL。中身は、安全領域を避ける (既定) か無視する (`ignoresSafeArea`) かを SwiftUI の標準の書き方で選べる。

- 届けるのはシステムの領域 (ステータスバー・ホームインジケータ等、UIKit の safe area にあたるもの) だけで、キーボードの領域は含めない
- 中央の軸の辺では、重なりがあっても安全領域を受け取らない (0)
- 窓の寸法や窓の安全領域が表示中に変わったら、中身が受け取る値も新しい重なりになる
- KMP の Swift 面から登録した SwiftUI の中身も同じく受け取る

**Side Effects**: なし

#### Scenario: [PB-IS-01] 窓全体基準で上端に付けた Dialog の中身は、上の重なりを受け取る
- **GIVEN** 縦長の窓と、基準領域を窓全体にし、垂直の配置を上端にした SwiftUI の中身の Dialog
- **WHEN** Dialog を表示する
- **THEN** 中身が受け取る安全領域は上 59・下 0・左右 0 である

#### Scenario: [PB-IS-02] 窓全体基準で下端に付けた Dialog の中身は、下の重なりを受け取る
- **GIVEN** 縦長の窓と、基準領域を窓全体にし、垂直の配置を下端にした SwiftUI の中身の Dialog
- **WHEN** Dialog を表示する
- **THEN** 中身が受け取る安全領域は上 0・下 34・左右 0 である

#### Scenario: [PB-IS-03] 窓全体基準で全面に広げた Dialog の中身は、両辺の重なりを受け取る
- **GIVEN** 縦長の窓と、基準領域を窓全体にし、両軸の配置を全面 (fill) にした SwiftUI の中身の Dialog
- **WHEN** Dialog を表示する
- **THEN** 中身が受け取る安全領域は上 59・下 34・左右 0 である

#### Scenario: [PB-IS-04] 中央に置いた Dialog の中身は、重なりがあっても安全領域を受け取らない
- **GIVEN** 縦長の窓と、基準領域を窓全体にし、両軸を中央に置いた、理想の高さ 800 を求める SwiftUI の中身の Dialog (上下とも安全領域に重なる)
- **WHEN** Dialog を表示する
- **THEN** 中身が受け取る安全領域は上下左右とも 0 である

#### Scenario: [PB-IS-05] 窓全体基準で端に付けた Loading の中身は、重なりを受け取る
- **GIVEN** 縦長の窓と、基準領域を窓全体にし、垂直の配置を上端にした SwiftUI の中身の Loading
- **WHEN** Loading を表示する
- **THEN** 中身が受け取る安全領域は上 59・下 0 である

#### Scenario: [PB-IS-06] 窓全体基準で端に付けた Toast の中身は、重なりを受け取る
- **GIVEN** 縦長の窓と、基準領域を窓全体にし、垂直の配置を下端にした SwiftUI の中身の Toast
- **WHEN** Toast を表示する
- **THEN** 中身が受け取る安全領域は上 0・下 34 である

#### Scenario: [PB-IS-07] 窓が変わると、受け取る安全領域も新しい重なりになる
- **GIVEN** 縦長の窓に、基準領域を窓全体にし、水平の配置を右端・垂直の配置を上端にした SwiftUI の中身の Dialog が表示されている
- **WHEN** 窓を横長に変える
- **THEN** 中身が受け取る安全領域は、変える前は上 59・右 0、変えた後は上 0・右 59 である

#### Scenario: [PB-IS-08] キーボードの領域は届けない
- **GIVEN** SwiftUI の中身を載せたホスト
- **WHEN** ホストが中身へ渡す安全領域の種類を確かめる
- **THEN** システムの領域だけを渡し、キーボードの領域を渡さない設定になっている

#### Scenario: [PB-IS-09] 比率サイズを伴う全面の軸は中央の軸として扱う
- **GIVEN** 縦長の窓と、基準領域を窓全体にし、垂直の配置を全面 (fill)・高さの比率を 0.99 にした SwiftUI の中身の Dialog (上下とも安全領域に重なる)
- **WHEN** Dialog を表示する
- **THEN** 中身が受け取る安全領域は上下とも 0 である

### Requirement: 安全領域を受け渡しても、器の大きさと位置は変わらない

SwiftUI の中身の器の大きさと位置は、中身が受け取る安全領域に左右されない SHALL。器へ伝える要求サイズは、中身が安全領域を受け取らないときと同じ値である。端に付けた中身は器の内側で安全領域を避け、使える大きさが重なりの分だけ減る。

- 安全領域を無視する中身 (`ignoresSafeArea`) で、大きさが可変のものは、器の矩形も中身の位置と大きさも、安全領域を受け取らない場合と同じになる
- 固定サイズの指定で器の内側の安全領域に収まらない中身は、器の矩形は変わらないが、器の内側での並び方は SwiftUI 標準のホストと同じ規則に従う (安全領域を無視する指定があっても、下端では並び方が動くことがある)
- 中央に置いた中身は、安全領域に重なっても要求サイズより大きくならない
- 中身の要求サイズが表示中に変わったら、器はその新しい大きさに追従する
- UIView で書いた中身の扱いは変えない (UIKit の伝播で、重なりを safe area として受け取ったまま)

**Side Effects**: なし

#### Scenario: [PB-IS-10] 端に付けた中身の器は、要求サイズのまま
- **GIVEN** 縦長の窓と、基準領域を窓全体にし、垂直の配置を上端 / 下端にした SwiftUI の中身の Dialog
- **WHEN** Dialog を表示し、1 秒間測り続ける
- **THEN** 器の矩形はずっと高さ 100 で、上端なら y 0、下端なら y 752 から動かない。中身は器の内側の安全領域の中に収まる (上端なら y 59 から y 100 まで、下端なら y 752 から y 818 まで)

#### Scenario: [PB-IS-11] 安全領域を無視する中身は、今と同じ位置と大きさ
- **GIVEN** 縦長の窓と、基準領域を窓全体にし、垂直の配置を上端 / 下端にした、一番外側で安全領域を無視する SwiftUI の中身の Dialog
- **WHEN** Dialog を表示する
- **THEN** 器の矩形は上端なら y 0・高さ 100、下端なら y 752・高さ 100 で、中身もその矩形いっぱい (同じ位置・高さ 100) にある

#### Scenario: [PB-IS-12] 安全領域に収まらない固定サイズの中身でも、器の矩形は変わらない
- **GIVEN** 縦長の窓と、基準領域を窓全体にし、垂直の配置を上端 / 下端にした、固定サイズ 200 × 100 を指定し、一番外側で安全領域を無視する / 無視しない SwiftUI の中身の Dialog
- **WHEN** Dialog を表示し、1 秒間測り続ける
- **THEN** 器の矩形はずっと上端なら y 0・高さ 100、下端なら y 752・高さ 100 である

#### Scenario: [PB-IS-13] 中央に置いた中身は膨らまない
- **GIVEN** 縦長の窓と、基準領域を窓全体にし、両軸を中央に置いた、理想の高さ 800 を求める SwiftUI の中身の Dialog
- **WHEN** Dialog を表示し、1 秒間測り続ける
- **THEN** 器の矩形はずっと y 26・高さ 800 である

#### Scenario: [PB-IS-14] 中身の要求サイズが変わると、器が追従する
- **GIVEN** 縦長の窓に、基準領域を窓全体にし、垂直の配置を上端にした SwiftUI の中身の Dialog が表示されている
- **WHEN** 中身が求める理想の高さを 160 に変える
- **THEN** 器の高さは 160 になり、中身が受け取る安全領域は上 59 のまま

#### Scenario: [PB-IS-15] 横の安全領域で折り返す本文でも、器の矩形は落ち着く
- **GIVEN** 横長の窓と、基準領域を窓全体にし、水平の配置を左端にした、窓の幅を超える長さの本文 (折り返しを許す) を持つ SwiftUI の中身の Dialog
- **WHEN** Dialog を表示し、1 秒間測り続ける
- **THEN** 器の矩形は 1 秒間変わらず、幅は窓の幅 852 で頭打ちになる。中身が受け取る安全領域は左 59・右 0 である

#### Scenario: [PB-IS-16] UIView の中身は、今と同じく重なりを safe area として受け取る
- **GIVEN** 縦長の窓と、基準領域を窓全体にし、垂直の配置を上端にした、高さ 100 の UIView の中身の Dialog
- **WHEN** Dialog を表示する
- **THEN** 中身の safe area は上 59・下 0 で、器の高さは 100 である

### Requirement: 窓全体以外の基準領域では、SwiftUI の中身は安全領域を受け取らない

基準領域が可視領域 (既定) か表示中のページのとき、SwiftUI の中身が受け取る安全領域は、移動量 (offset) などで中身がシステムの領域に重なっても 0 であり、器の矩形も中身の位置も今と同じである SHALL。

**Side Effects**: なし

#### Scenario: [PB-IS-17] 既定の基準領域で端に付けた Dialog の中身は、安全領域を受け取らない
- **GIVEN** 縦長の窓と、基準領域を指定せず (可視領域)、垂直の配置を上端 / 下端にした SwiftUI の中身の Dialog
- **WHEN** Dialog を表示する
- **THEN** 中身が受け取る安全領域は 0 で、器の矩形は上端なら y 59・高さ 100、下端なら y 718・高さ 100 である

#### Scenario: [PB-IS-18] 既定の基準領域で移動量によりシステムの領域に重なっても、安全領域を受け取らない
- **GIVEN** 縦長の窓と、基準領域を指定せず (可視領域)、垂直の配置を上端・垂直の移動量を -30 にした SwiftUI の中身の Dialog (上に 30 重なる)
- **WHEN** Dialog を表示する
- **THEN** 中身が受け取る安全領域は 0 で、器の矩形は y 29・高さ 100 である

#### Scenario: [PB-IS-19] 既定の基準領域の Toast の中身は、安全領域を受け取らない
- **GIVEN** 縦長の窓と、レイアウトを指定しない SwiftUI の中身の Toast
- **WHEN** Toast を表示する
- **THEN** 中身が受け取る安全領域は 0 である

# Deviation: add-layout-spec

実装フェーズ中のオーナー指示による、デルタスペック・承認済みモックとの合意済み差分。

- レイアウトデモ項目 (属性調整パネル) / ui/mock/approved-layout-panel.png: モックとスペックはパネル画面からの戻る導線を未定義 → 指示により appbar 左に戻る導線 (`‹`) を追加 (A案)。理由: パネルを残して配置を連続で試せるデモ用途を優先し、承認済みメニュー画面は無改変とする (2026-08-18)
- 結果表示エリアの表示条件 / samples spec Scenario「メニュー画面に戻ると直近の結果が表示される」: スペックはメニューの結果エリアのみを規定し、モックにパネル側の結果表示は無い → 指示によりパネル画面にも直近結果 (confirmed / cancelled) を表示する。メニュー側の Scenario は従来どおり維持。理由: 配置を連続で試すデモでその場で結果が見えるようにする (2026-08-18)

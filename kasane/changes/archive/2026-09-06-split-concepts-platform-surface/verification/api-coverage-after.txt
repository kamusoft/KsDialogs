## 前回実行 (是正前) との差

初回実行では 検査 [1] が 44 件 (ios 22 / android 10 / maui 8 / aiforms-migration 4 / kmp 0)、
検査 [2] が 3 件 (maui) 一致していた。全件を実装と源泉 concept で照合した結果、Skill 側に他 platform 名が
写り込んだものは 1 件も無く、すべて **禁止集合側の誤り (task 4.3 の混入) に由来する偽陽性**だった。
禁止集合を是正した後の再実行が上の出力である。原因・適用した規則・外したトークンの一覧と出典は
`verification/baseline.md`「追記: ios / android / maui / aiforms-migration 禁止集合の是正 (task 6.1)」に記録した。

集合の件数: ios 200 → 192 / android 178 → 171 / maui 154 → 142 / aiforms-migration 151 → 144 /
kmp 142 (変更なし)。`maui` の `concept-exempt` 3 件は、対象トークンを集合から外したため空になった。

## 検査 [2] の候補 23 行について

`api-coverage-check.py` の 23 行は「源泉 concept に出る名前のうち Skill に載っていないもの」の報告であり、
禁止集合との一致が 0 件になった今も残る (掲載除外の判断済み候補)。仕分けは task 6.2 の除外リストが引き取る。
`SetIocConfig` / `ShowResultAsync` / `UseCurrentPageLocation` (maui) は `maui/api/` の「移植元との対応」節が
旧 AiForms の名前として言及しているものを拾った候補で、**MAUI Skill に載っていないこと自体が正しい**
(閉世界性)。他 platform 名の混入検出という禁止集合の目的の外なので maui 集合から外し、
書き直し後の除外リストでは「非 API token」として仕分けた。

## 追記: オーナー判断による掲載 (2026-09-06)

暫定確定していた除外 4 名 (`Center` / `Fill` / `Top` / `ToastStyle.BuiltinBackgroundColor`) をオーナー判断で
掲載に倒し、移行 Skill (`skills/{en,ja}/ksdialogs-aiforms-migration/references/api-mapping.md`) の散文へ

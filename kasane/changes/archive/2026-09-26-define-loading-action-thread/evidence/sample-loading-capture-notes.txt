# Sample の Default Loading / Custom Loading の通し (LD-HS-01・LD-HS-02) の撮影記録

撮影日: 2026-09-25 (MAUI iOS の 3 枚は同日に撮り直し)
対象: 作業ツリーの変更後のライブラリ + tasks 5.1・5.2 の Sample (4 ルート、MAUI は iOS と Android の両方)
共通の手順:
  - 起動引数 loading-step-interval-ms で刻みを延ばして起動し (demo は渡さない)、メニューの行をタップして撮る。
    iOS 系は `--loading-step-interval-ms <ms>`、Android 系は `--es loading-step-interval-ms <ms>`。
    撮影のためのソース改変はしていない。
  - demo 引数での自動再生を使わなかった理由: この Simulator では、起動直後の自動再生で Loading が画面に出ない
    (変更前のビルドでも同じ。Basic Dialog の自動再生は提示に失敗して assertionFailure で止まる)。
    今回の変更とは無関係の既存の事象として別途報告する。Scenario の WHEN はタップなので、タップで撮った。
  - iOS 系のタップはシミュレータ操作ツール (device point)、Android 系は adb shell input tap (物理ピクセル)。
端末:
  - iOS: iOS Simulator (iPhone Air、iOS 26.5) を別途 boot して使用 (起動中の Simulator は流用していない)。Debug 構成。
  - Android native / MAUI Android: Android エミュレータ (API 31。ステータスバーはデモモードで時計が 9:41 固定)。
  - KMP Android: Pixel 4a 実機 (API 33)。ステータスバーの通知アイコン領域 (時計と Wi-Fi の間) を塗りつぶしている。

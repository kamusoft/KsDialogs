# loading-contract デルタ (define-loading-action-thread)

Scenario ID は `LD-TH-<NN>` (Loading のスコープ形の action が始まるスレッド)。挙動は Native 2 実装 (iOS / Android) の同名テストで全量を検証する (core/ADR-0016)。MAUI と KMP は、指定の引き回しと各形態の切り替え口を、それぞれの能力のデルタで検証する。既存の Loading 契約 (合流・進捗・失敗・終了の時点) は変えない — 本書は action が始まるスレッドの定めの追加分のみ。決定の出典は core/ADR-0037。

## ADDED Requirements

### Requirement: スコープ形の action が始まるスレッド

スコープ形 (既定ローディング・インスタンス渡し・インライン・型指定のすべての入口) の action は、**既定で UI スレッドで始まる** (SHALL)。入口で「UI スレッド外で始める」を指定すると、action は **UI スレッド外で始まる** (SHALL)。どちらの場合も、呼び出し元のスレッドに関係なく保証する。「どこで始まってもよい」にあたる選択肢は無い。

指定の表し方は形態ごとに異なる (ios-native / android-native / maui-binding / kmp-facade の各デルタ)。

この保証には、次の 2 つの範囲の定めがある。
- **処理自身が実行スレッドを型で宣言している場合**: その宣言が優先される。対象は、実行スレッドを関数の型で宣言できる言語 (Swift の isolation) だけで、その場合の扱いは ios-native デルタが定める
- **UI スレッドを持たない実行環境**: 保証の対象は、UI スレッドを持つ実行環境 (iOS / Android) だけである。UI スレッドを持たない環境 (MAUI の素の .NET) での扱いは、maui-binding デルタが定める

「始まる」は、action の本体の最初の文が実行されるスレッドを指す。action の中で await した後にどのスレッドへ戻るかは各言語の規則に従い、この契約は保証しない。

指定は、action の実行以外の既存の契約を変えない。
- 処理は表示状態によらず必ず実行される
- 失敗 (例外・キャンセル) は合流 1 件の終了として数えたうえで呼び出し元へ伝播する
- 進捗の報告口とメッセージ更新は、action がどちらのスレッドで動いていても呼べ、受理の順序も変わらない

#### Scenario: [LD-TH-01] 既定では、UI スレッドから呼んでも UI スレッドで始まる
- **GIVEN** 既定ローディングのスコープ形
- **WHEN** UI スレッドから、指定なしで開始する
- **THEN** action の本体の最初の文は UI スレッドで実行される

#### Scenario: [LD-TH-02] 既定では、UI スレッド外から呼んでも UI スレッドで始まる
- **GIVEN** 既定ローディングのスコープ形
- **WHEN** UI スレッド外から、指定なしで開始する
- **THEN** action の本体の最初の文は UI スレッドで実行される

#### Scenario: [LD-TH-03] UI スレッド外の指定では、UI スレッドから呼んでも UI スレッド外で始まる
- **GIVEN** 既定ローディングのスコープ形
- **WHEN** UI スレッドから、UI スレッド外で始める指定をして開始する
- **THEN** action の本体の最初の文は UI スレッド外で実行される

#### Scenario: [LD-TH-04] UI スレッド外の指定では、UI スレッド外から呼んでも UI スレッド外で始まる
- **GIVEN** 既定ローディングのスコープ形
- **WHEN** UI スレッド外から、UI スレッド外で始める指定をして開始する
- **THEN** action の本体の最初の文は UI スレッド外で実行される

#### Scenario: [LD-TH-05] カスタム View の入口でも、既定は UI スレッドで始まる
- **GIVEN** 登録済みのカスタム Loading View
- **WHEN** インスタンス渡し・インライン・型指定のそれぞれのスコープ形を、UI スレッド外から指定なしで開始する
- **THEN** どの入口でも、action の本体の最初の文は UI スレッドで実行される

#### Scenario: [LD-TH-06] カスタム View の入口でも、UI スレッド外の指定が効く
- **GIVEN** 登録済みのカスタム Loading View
- **WHEN** インスタンス渡し・インライン・型指定のそれぞれのスコープ形を、UI スレッドから UI スレッド外で始める指定をして開始する
- **THEN** どの入口でも、action の本体の最初の文は UI スレッド外で実行される

#### Scenario: [LD-TH-07] UI スレッド外で始まった action からの進捗報告が届く
- **GIVEN** 進捗の受け口を持つカスタム Loading View
- **WHEN** UI スレッド外で始める指定をして開始し、action の中から進捗を順に報告する
- **THEN** 報告した進捗が、報告した順に進捗の受け口へ届き、最後の報告が終了に追い越されない

#### Scenario: [LD-TH-08] どちらの指定でも、action の失敗は伝播して表示が閉じる
- **GIVEN** 既定ローディングのスコープ形
- **WHEN** 指定なしと UI スレッド外の指定のそれぞれで開始し、action の中で例外を投げる
- **THEN** どちらの場合も、例外が呼び出し元へ伝播し、Loading は閉じる (合流 1 件の終了として数えられる)

# iosMain metadata compile の回復証跡 (2026-09-05、Kotlin 2.4.10 / Gradle 9.7.0)

## 修正前 (再現)

kmp/ で `./gradlew :ksdialogs-kmp:compileIosMainKotlinMetadata --rerun-tasks`:

e: .../kmp/ksdialogs-kmp/src/iosMain/kotlin/jp/kamusoft/ksdialogs/kmp/IosLoadingGateway.kt:34:5 Member overrides different '@Throws' filter from 'interface KsLoading : Any'.
e: .../kmp/ksdialogs-kmp/src/iosMain/kotlin/jp/kamusoft/ksdialogs/kmp/IosLoadingGateway.kt:57:5 Member overrides different '@Throws' filter from 'interface KsLoading : Any'.
e: .../kmp/ksdialogs-kmp/src/iosMain/kotlin/jp/kamusoft/ksdialogs/kmp/IosToastGateway.kt:30:5 Member overrides different '@Throws' filter from 'interface KsToast : Any'.
Execution failed for task ':ksdialogs-kmp:compileIosMainKotlinMetadata'
BUILD FAILED in 44s

切り分け (iosMain の一時ファイルで実施、終了後に削除):
- iosMain 内で閉じた interface + 同じ @Throws の override → 通る
- commonMain の KsToast を iosMain で override し @Throws を書かない → 通る
- commonMain の interface を iosMain で override し同じ @Throws を書く (修正前) → 失敗
根本原因: https://youtrack.jetbrains.com/issue/KT-88548 (affected 2.4.10、fixed 2.5.0-Beta1)

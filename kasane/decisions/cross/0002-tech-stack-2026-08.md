## Context

KsDialogs は実装ゼロのグリーンフィールドであり、破壊的メジャーに乗るなら移行コストゼロの今が最安タイミング (KsAppKMP cross/ADR-0001 の判断型)。一般公開予定のライブラリであり、特定の消費者プロジェクトに下限を拘束されない広い間口を前提とする。プラットフォーム構成は core/ADR-0001 (Native 2実装 + MAUI / KMP 薄いラッパー) で確定済みで、KMP iOS 側は Kotlin から Swift 実装を呼ぶ必要がある。最低対象 OS は KsAppKMP にも決定記録がなく (minSdk 24 / iOS 17.0 はプロジェクト設定の実測値)、本 ADR が新規判断となる。

## Decision

2026-08 時点の最新安定セットで開始し、以後は追従型の小差分に収める:

- **Kotlin / KMP**: 2.4 系最新 (2.4.10、KsAppKMP と同版)
- **ビルド**: Gradle 9.7.0 / AGP 9.3.0
- **KMP→Swift interop**: Swift 実装に `@objc` 互換面を出して cinterop でバインドする。公式 Swift Export は Alpha (production 非推奨) のため見送り (KsAppKMP core/ADR-0003 と同判断)。将来 Swift Export へ剥がせる API 設計を意識する
- **iOS**: Xcode 26.6 / Swift 6.3 / **swift-tools-version 6.3** (モノレポ scaffold の実物 (add-monorepo-scaffold) で確定。実測環境は Xcode 26.5 / Swift 6.3.2 — iOS SDK は 26.6 と同一の 26.5、Swift はパッチ差のみのため、この実測をもって確定とした)
- **.NET / MAUI**: net10.0 (LTS) を土台とする。.NET 11 は STS (GA 2026-11-10) のため、GA 後に TFM 追加で対応する
- **最低対象 OS**: iOS 17 / Android minSdk 24 (Android 7.0)
- **最低対象 OS の更新ルール**: 年1回 (本 ADR の起点月である8月目安) に市場相場を調査して見直す。引き上げ幅は固定せず都度の相場判断とし、引き上げ時は本 ADR を supersede する

## Alternatives Considered

- **最低 OS を 2026 年相場 (iOS 16 / minSdk 31) にする案** — 却下。一般公開ライブラリとして広い間口を優先する。minSdk 24 はほぼ全端末をカバーし、ダイアログ提示に高い API level は不要
- **最低 OS の更新を「毎年 +1」の機械ルールにする案** — 却下。相場の動きは年により異なり (Android 推奨相場は年 +2 ペースの時期もある)、固定幅より都度の相場調査に基づく判断のほうが実態に合う
- **最低 OS を広め (iOS 16 / minSdk 24) にする案** — 却下。a 案との差は iOS 16 対応のみで、iOS は新版普及が速く (iOS 18 が12ヶ月で84%)、ダイアログ提示系で iOS 17 API を分岐なしで使える利点が勝つ
- **Swift Export を採用する案** — 却下。Kotlin 2.4.0 で Alpha 昇格したが production 非推奨。KsAppKMP core/ADR-0003 と同判断で KMP-NativeCoroutines 系の実績ある構成に寄せる
- **Gradle を KsAppKMP と同版 (9.5.0) に固定する案** — 却下。判断型は「最新安定に乗る」であり、追従型の小差分に収める方針と整合する 9.7.0 を採る

## Consequences

- 正: 新世代セットでの開始により、将来の破壊的移行を全形態で背負うリスクを回避する
- 正: 一般公開ライブラリとして広い端末カバレッジ (minSdk 24 ≒ ほぼ全端末) を確保する
- 正: Kotlin / minSdk が KsAppKMP と揃い、トラブルシュート知識の共有と搭載互換が副次的に得られる
- 正: iOS 17 下限により提示系 API・Observation を互換分岐なしで使える
- 負: 最新版ゆえに Web 上の事例・トラブル情報が少なく、自力解決の比重が高い
- 負: iOS 16 以下の端末は対象外になる
- 負: `@objc` 互換面の制約 (async / ジェネリクス / Swift 値型を ObjC 面に出せない) が KMP から呼ぶ Swift ファサードの API 形状を制約する
